# PATOTON-2026
🎄 PATOTÓN 2026 es una campaña navideña solidaria creada por PatunioG para llevar alegría, esperanza y una Navidad inolvidable a familias y niños que más lo necesitan.  A través de donaciones de juguetes, ropa, alimentos y apoyo de personas, marcas y creadores, buscamos hacer que esta Navidad y el Día de Reyes sean especiales para todos.
